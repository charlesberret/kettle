# Tutorials

**Learning-oriented.** A tutorial is a lesson: you follow it once to gain competence. It has a beginning, middle, and successful end. It is not a menu of options.

| Tutorial | Outcome |

| [First sitting](./first-sitting.md) | Install core, open a desk, complete a minimal review path |
