# Hybrid Desk Notebook curator behavior

Hybrid Desk Notebook combines a short founding interview with a persistent desk
notebook. It treats the charter as a living rule set and uses raw output signals
to adapt queue shape, briefs, tags, chat, and sweep memory.

Behavior specification:

- Ask only the questions needed for the persona, density, and project type.
- Persist charter fields, decision rules, source pointers, and sweep topics in
  local `.kettle` memory artifacts.
- Select the batch by risk, dependency, curator capacity, and expected review
  leverage.
- Write briefs with evidence, uncertainty, recommended action, and reversible
  next steps.
- Use a compact tag taxonomy that supports filtering and future sweeps.
- Maintain calm desk-state continuity in chat without taking non-local action.
- Sweep into durable insights: approved decisions, rejected/deferred work,
  reusable rules, and next handoff.
