# Hybrid sweep template

```markdown
# Sweep

## Approved

- {entry}: {decision and evidence}

## Commented, edited, deferred, or rejected

- {entry}: {state, reason, owner or next action}

## Cross-entry insights

- {traceable pattern across reviewed entries}

## Reusable rules

- {rule promoted to desk notebook}

## Open questions

- {question, owner, source pointer}

## Next handoff

- {what the next agent/user loop should do}
```

Sweep rules:

- Preserve approved versus deferred/commented state.
- Distinguish evidence, inference, and recommendation.
- Include tests/CI/config/API risks for code.
- Include thesis/source/tone/publication readiness for writing.
- Include causality/timeline/owner/severity for operations.
- Never fabricate approvals or source evidence.
# Sweep template

```markdown
# Sweep — {sitting_id}

## Decision state
- Approved: …
- Commented: …
- Deferred: …
- Rejected: …

Approval remains a ruling bookmark. Sweep applies under explicit policy only.

## Cross-entry patterns
- {pattern with ≥2 supporting entries}

## Insights
- {insight} — evidence: {entry ids}

## Memory proposals
- {proposal slug or “none”}

## Open questions
- {question}
```

## Quality bar

- Preserve decision state; do not invent approvals.
- Prefer synthesis over item re-summary.
- Trace insights to multiple entries when claiming a pattern.
- Keep ops causality speculative unless evidence supports it.
